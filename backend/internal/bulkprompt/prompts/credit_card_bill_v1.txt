Credit-card bill processor and output contract v1:

document_summary is required and is an object with exactly:
{
  "card_account_ref": null,
  "period_start": null,
  "period_end": null,
  "statement_date": null,
  "due_date": null,
  "settlement_currency": null,
  "amount_due_minor": null,
  "minimum_payment_minor": null,
  "previous_balance_minor": null,
  "evidence": []
}
Dates are null or YYYY-MM-DD. period_start cannot follow period_end; statement_date cannot follow due_date. settlement_currency is null or an uppercase three-letter ISO 4217 code. amount_due_minor is null or a positive integer. minimum_payment_minor and previous_balance_minor are null or non-negative integers. Summary metadata is never itself a transaction.

Summary evidence.field is exactly one of document_summary.card_account_ref, document_summary.period_start, document_summary.period_end, document_summary.statement_date, document_summary.due_date, document_summary.settlement_currency, document_summary.amount_due_minor, document_summary.minimum_payment_minor, document_summary.previous_balance_minor. Cite every non-null source-derived summary field exactly once. card_account_ref evidence is required only when multiple accounts are allowed.

transactions is a JSON array, using [] when no statement lines are visible. Every item has exactly this shape:
{
  "candidate": {
    "line_index": 1,
    "line_kind": "activity",
    "transaction_kind": "debit",
    "title": "Merchant or statement line description",
    "merchant_name": "Merchant when visible, otherwise empty",
    "original_amount_minor": 1250,
    "original_currency": "SGD",
    "sgd_amount_minor": null,
    "occurred_on": "2026-08-04",
    "time_precision": "date",
    "references": [],
    "account_ref": "",
    "account_evidence": {
      "card_last_four": "",
      "masked_bank_reference": "",
      "additional_identifiers": []
    },
    "line_items": [],
    "category_leaf_name": "",
    "possible_internal_transfer": false
  },
  "evidence": []
}

line_index is a unique positive integer within this chunk. line_kind is exactly activity, refund, fee, interest, or payment. activity, fee, and interest use transaction_kind "debit". refund and payment use transaction_kind "credit". original_amount_minor is a positive integer. sgd_amount_minor is null unless an SGD amount is explicitly shown; when present it is a positive integer. title is non-empty. Optional strings use "" when unavailable. references and additional_identifiers contain only non-empty source values.

account_evidence is always an object. card_last_four is "" or exactly four digits. masked_bank_reference is "" or a source-visible masked/suffix account reference. additional_identifiers is an array of other source-visible account identifiers. account_evidence requires one evidence entry only when at least one of its values is populated.

line_items is [] unless reliable item-level detail is visible. Every line item has exactly:
{
  "schema_version": 1,
  "description": "Non-empty description",
  "quantity": 1,
  "unit_price_minor": null,
  "line_total_minor": null,
  "tax_minor": null,
  "discount_minor": null,
  "currency": "SGD",
  "details": {}
}
quantity is a positive integer. currency equals the candidate original_currency. Optional line-item amounts are null or non-negative integer minor units. details is a JSON object for extra source-visible item facts. A non-empty line_items array requires one transaction evidence entry with field "line_items".

Transaction evidence.field is exactly one of:
transaction_kind, title, merchant_name, original_amount_minor, original_currency, sgd_amount_minor, occurred_on, references, account_ref, account_evidence, line_items, category_leaf_name, possible_internal_transfer, line_index, line_kind.

Evidence is required for transaction_kind, title, original_amount_minor, original_currency, occurred_on, line_index, and line_kind. Evidence is also required for each populated optional field, including possible_internal_transfer when true. account_ref evidence is required only when multiple accounts are allowed. Do not emit evidence for time_precision.

The top-level object has exactly:
{
  "schema_version": 1,
  "document_summary": {},
  "transactions": []
}
